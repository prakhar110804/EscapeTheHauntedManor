# 🏚️ Escape The Haunted Manor

A text-based adventure game developed in Python.

## 📖 Story

You are trapped inside a mysterious haunted manor hidden deep within Blackwood Forest. Explore rooms, collect items, solve puzzles, battle supernatural creatures, and escape before sunrise.

## ✨ Features

- Interactive story
- Multiple endings
- Inventory system
- Health & lives
- Combat mechanics
- Save & Load game
- Puzzle solving

## 🛠️ Technologies Used

- Python 3.13
- Rich (for terminal UI)

## 🚀 How to Run

```bash
python main.py
```
